# Intaglio-Travel-Poster

A reusable image-generation Skill for converting travel, architecture, landscape, cityscape, or portrait photography into **16:9 horizontal fictional intaglio security-print study posters**.

## Core principles

- Preserve the original photograph's identity, geometry, viewpoint, perspective, lighting, and spatial relationships.
- Rebuild the scene with fine intaglio engraving linework, cross-hatching, stippling, and low-saturation multi-color printing.
- Use abstract, fictional guilloche and security-print ornament only as supporting decoration.
- Keep location typography minimal and accurate.
- Never reproduce real currency, denominations, issuing institutions, official seals, serial numbers, or identifiable banknote layouts.

See [SKILL.md](./SKILL.md) for the complete generation logic.
